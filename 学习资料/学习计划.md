# 《易经》学习计划

## 目标

先由 Codex 回到三本书中备课，理解《易经》的文本、结构和核心观念，再用一课一个知识点的方式带用户学习。学习过程以语音交流为主，文件沉淀为辅：每天聊完后，把已学内容、困惑、关键领悟和下一课写入学习进度。

## 三本书怎么分工

### 1. 《易经(白话全译)》：主课本

这本书是学习主线。它把《易经》定位为一部帮助人认知世界、认知自己、理解变化和处境的经典，不把它简化为神秘占断。全书主体是六十四卦，按经上、经下分为两章，每卦都有原文、译文、解读。

学习时先以它为准，先读原文和白话解释，再进入卦象、爻位、义理和现实启发。

### 2. 《曾仕强-易经的智慧》：辅助讲解

这本像讲义或课程笔记，适合帮助入门。它从“何为易经”“何为阴阳”“何为太极”等问题讲起，语言更口语化，会用现代比喻解释伏羲八卦、文王六十四卦、孔子《易传》等线索。

学习时用它来帮助理解，但不让它替代主书。

### 3. 《易经真的很容易》：图解辅助

这本是图片型 PDF，适合作为视觉化、入门化材料。它不适合第一轮全文 OCR，但适合在遇到图像、八卦、太极、卦象关系时按页查看。

学习时按需调图，不一开始做全书转换。

### 4. 外部知识库：补充材料

本地还有两个知识库，登记在 `学习资料/外部知识库.md`。

`metaphysics-classics-guide` 适合补充《周易》在术数经典体系中的位置，以及阴阳五行、术语、书目关系。

`nihaisha-tianji` 适合在讲六十四卦、卦象、象数、倪海厦天纪“人道”视角时补充。

它们只做补充和对照，不替代主书。

## 《易经》大体在讲什么

《易经》表面上是六十四卦，深层是在讲“变化中的秩序”。它关心的不是把未来说死，而是帮助人看懂：事物处在什么阶段，力量如何消长，什么时候该进，什么时候该退，什么时候该守，什么时候该变。

可以先记住四句话：

- 它讲变化：世界不是静止的，人的处境也一直在变。
- 它讲关系：阴阳、刚柔、上下、内外、动静都要放在关系中看。
- 它讲时位：同一件事，在不同时间、不同位置，意义不一样。
- 它讲修养：读卦不是为了神秘化，而是训练判断、分寸、耐心和行动。

## 为什么这样学

《易经》难，不是因为它故意玄，而是因为它同时有三层东西：

- 符号层：太极、阴阳、八卦、六十四卦。
- 文本层：卦辞、爻辞、彖传、象传、文言传。
- 义理层：变化、时机、处境、修养和行动选择。

如果一上来直接读六十四卦，会很容易迷路；如果只讲概念，又会脱离原文。所以学习顺序应该是：先建立地图，再学读法，然后用乾坤两卦做示范，最后进入六十四卦。

## 学习路线

### 第一阶段：打开《易经》的门

目标：知道《易经》不是一本“玄学答案书”，而是一套观察变化与处境的语言。

课程：

1. 什么是“易”：为什么要从变化的眼光读起。
2. 什么是《周易》：经、传、三圣三古大概是什么。
3. 为什么《易经》难读：符号、古文、义理三层叠在一起。
4. 学《易经》先不要急着占断：先学会看处境和分寸。

### 第二阶段：建立基础概念

目标：先把读卦必需的工具学会。

课程：

1. 太极：为什么说变化背后有一个整体。
2. 阴阳：为什么一切都要放在相对关系里看。
3. 三才：天、地、人分别代表什么。
4. 八卦：八种基本处境和自然象。
5. 六十四卦：为什么八卦要重叠成六十四卦。

### 第三阶段：学会读一卦

目标：知道看到一卦时应该先看什么、后看什么。

课程：

1. 卦名：它给这个处境起了什么名字。
2. 卦象：上下卦组合说明什么。
3. 卦辞：整体判断和方向。
4. 爻辞：六个阶段的变化。
5. 彖传、象传、文言传：后人怎样解释卦义。

### 第四阶段：乾坤示范

目标：用乾卦和坤卦建立读卦模板。

课程：

1. 乾卦：自强不息、时机、进退、盛极而戒。
2. 坤卦：厚德载物、承载、柔顺、阴极返阳。
3. 乾坤关系：刚柔、主从、创造与承载。
4. 用九与用六：刚柔转换，不执一端。

### 第五阶段：六十四卦逐步学习

目标：按经上、经下推进，每次只讲一个核心知识点或一卦。

方式：

- 每卦先读主书原文、译文、解读。
- 再找出这一卦最值得记住的处境。
- 必要时引用曾仕强讲义或图解书。
- 最后沉淀成一页学习笔记。

## 每天怎么学

建议每次语音学习 15 到 30 分钟。

每次学习遵循“先读薄 -> 再读厚 -> 最后再读薄”的节奏。

先读薄：先用简单道理讲清楚，不急着堆术语。

用例子落地：再用生活例子、类比或情境帮助理解。

再读厚：确认基础理解后，再补原文、卦象、体系位置和三书对照。

诵读句：每个知识点选一两句原文或关键句，不一定要求死背，但要让它成为记忆钩子。

最后再读薄：把展开后的内容压缩成几句能记住、能复述、能用出来的话。

注意：一课不等于一次回答。一个知识点默认需要多次交互：先讲一版，再听用户哪里清楚、哪里卡住；再换例子、补原文或调整说法。只有用户确认理解，或主动要求继续，才进入下一课。

每次只做五件事：

1. 回顾上一课一句话。
2. 读取今天主题的主书内容。
3. 讲一个核心知识点。
4. 用一个生活例子确认理解。
5. 更新学习进度：记录“进行中”或“已完成”，不要默认结课。

## 第一课建议

第一课先讲：什么是“易”，以及为什么《易经》要先从变化的眼光读起。

原因：如果先把“易=变化、关系、时位、分寸”理解住，后面读阴阳、八卦、乾坤、六十四卦时就不会把它们当成孤立符号，而会知道它们都是在描述变化中的处境。
