# 《易经》学习 Agent 与课程笔记

这个仓库记录一个以 Codex 为学习伙伴的《易经》长期学习项目。它公开的是 agent 配置、学习方法、课程路线和学习过程笔记；不公开原书 PDF、全文 TXT 或 OCR 结果。

## 仓库内容

- `AGENTS.md`：项目级 agent 指令，规定学习目标、文本依据、教学节奏、语音交互和边界。
- `.agents/skills/yijing-study/`：可复用的 Yi Jing study skill，要求先回到本地文本备课，再一课一个知识点地教学。
- `学习资料/学习计划.md`：课程路线、三本书分工、每课固定结构。
- `学习资料/学习进度.md`：当前学习进度、已形成的理解、用户困惑、下次主题。
- `学习资料/语音学习与学习模式.md`：说明 Qwen TTS 语音层、调用方式，以及这个学习模式如何建立。
- `学习资料/课程笔记-*.md`：每节课沉淀下来的过程笔记。
- `学习资料/外部知识库.md`：可选外部知识库的本地登记和使用边界。

## 如何使用

1. 克隆仓库后，在项目根目录放入你合法取得的本地学习资料，文件名建议与配置保持一致：

   ```text
   易经(白话全译).pdf
   易经(白话全译).txt
   曾仕强-易经的智慧.pdf
   易经真的很容易.pdf
   ```

2. 在 Codex 中打开项目目录，让 Codex 读取 `AGENTS.md` 和 `.agents/skills/yijing-study/SKILL.md`。

3. 开始学习时可以直接说：

   ```text
   今天继续
   ```

   或者指定主题：

   ```text
   用 $yijing-study 讲“阴阳和变化是什么关系”
   ```

4. 每次讲解前，agent 应先查主文本或已沉淀的学习资料，再用“先读薄 -> 用例子落地 -> 再读厚 -> 诵读句 -> 最后再读薄”的节奏教学。

5. 每轮学习后，把稳定的理解、困惑、关键领悟和下一步更新到 `学习资料/学习进度.md` 或对应课程笔记。

## 学习模式怎么建立

这个项目的学习模式不是一次性整理资料，而是逐步建立一个可复盘的学习闭环：

1. 用 `AGENTS.md` 固定项目规则：先读原文、再讲一个知识点、不要急着结课。
2. 用 `.agents/skills/yijing-study/SKILL.md` 固化 agent 行为：主书为依据，辅助书只作理解补充。
3. 用 `学习资料/学习计划.md` 建立课程路线：基础观念 -> 易经结构 -> 八卦 -> 读卦方法 -> 乾坤示范 -> 六十四卦。
4. 用 `学习资料/学习进度.md` 记录下一次从哪里继续。
5. 每次学习后，把用户复述、卡点、关键领悟和下一步写入课程笔记。

因此，“今天继续”不是重新开始，而是先读进度，再顺着上一轮的理解往下走。

## 学习原则

- 不急着给结论，先回到原文确认。
- 一课只聚焦一个核心知识点。
- 先建立可理解版本，再进入原文、卦象、爻位和三书对照。
- 不把传统文化解释包装成确定占断。
- 对术数、命理、风水、占卜等内容，只作为文化学习材料，不作现实决策保证。
