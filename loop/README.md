# Loop 复盘层

这个目录放项目的理解校准、学习收束和复盘规则。它不是考试系统，也不是单独的知识库，而是让每次学习从“听懂”进入“吸收、校正、沉淀”的闭环。

## 1. 理解校准 Loop

每个知识点讲到一定程度后，默认进入理解校准：

1. 用户用自己的话复述。
2. 用户给一个自己的工作、生活或学习例子。
3. Codex 判断哪里准确、哪里偏了。
4. 把校正后的理解写回课程笔记或学习进度。

这不是测验，也不是刷题；它的作用是确认知识有没有真正变成用户自己的理解。

## 2. 学习收束 Loop

用户说“今天到这儿”“今天先这样”，或者一次学习明显收束时，Codex 不直接结束，而是做一次学习闭环：

1. 回顾今天讲过的核心知识点。
2. 记录用户的复述、例子、困惑和校正点。
3. 更新课程笔记。
4. 更新 `学习资料/学习进度.md`，留下下次入口。
5. 追加当天学习记录到 `学习资料/学习记录/`。
6. 如果当天有实际学习记录，再生成或更新学习日报。
7. 如果流程本身暴露问题，把稳定改进写回 agent、TTS、资料索引或本目录规则。

## 3. 阴阳反馈模型

本项目把学习流程本身也按阴阳来复盘：

- 阳：Codex 输出讲解、推进课程、调用资料、播放语音。
- 阴：用户听、复述、追问、指出跳步、不稳或理解困难。
- 化：Codex 把反馈吸收进规则、脚本、笔记和下一次学习入口。

这层的目标是让学习系统自己也能被学习、被校正、被反补。
