# 三书使用地图

## 状态

初版。这个文件不是三本书的全文索引，而是课程使用地图：记录每本资料在学习中的分工、可检索方式、当前已定位的关键位置，以及后续讲课时应该怎样调用材料。

## 使用原则

1. 先用《易经(白话全译)》做主线依据。
2. 再用《曾仕强-易经的智慧》做口语化解释、现代比喻和入门入口。
3. 《易经真的很容易》主要用于图像、八卦、卦象关系等视觉辅助；它是图片型 PDF，按需渲染或 OCR，不默认全文 OCR。
4. 外部知识库只做补充和对照，不能替代主书定调。
5. 引入新卦名或新术语时，必须先说明读音、位置、结构、原文钩子和白话意思，再拿来做例子。

## 1. 《易经(白话全译)》

### 检索方式

- 有 `易经(白话全译).txt`，可以直接按关键词、卦名、原文检索。
- PDF 可用于页版式确认；课程讲解优先查 txt，再必要时看 PDF。

### 主书结构

正文六十四卦从 `易经(白话全译).txt` 第 237 行左右开始。

已定位的正文位置：

- 乾卦：第 237 行起。
- 坤卦：第 375 行起。
- 泰卦：第 1224 行起。
- 否卦：第 1315 行起。

### 当前课程已用关键位置

- 乾卦：第 240-242 行，乾为天、纯阳至健、天道运行；第 251 行“天行健，君子以自强不息”；第 266-268 行“潜龙勿用，阳在下也”；第 342 行“刚而能柔”；第 369 行提示乾坤《文言》是读卦示范。
- 坤卦：第 377-396 行，坤为地、纯阴、柔顺宽厚、承载化育；第 386 行“地势坤，君子以厚德载物”；第 473-480 行“用六”、柔而能刚、“坤至柔而动而刚”。
- 泰卦：第 1226 行，地天泰象征通泰；第 1231-1243 行，卦辞和《彖》《象》解释，重点是“天地交而万物通也；上下交而其志同也”；第 1287 行，上下交泰时三阴下降、三阳上升，阴阳合德；第 1309 行，泰极否来。
- 否卦：第 1317 行，天地否象征否闭；第 1322-1332 行，卦辞和《彖》《象》解释，重点是“天地不交而万物不通也；上下不交而天下无邦也”；第 1389 行，九五休否；第 1400 行，否终则倾。

## 2. 《曾仕强-易经的智慧》

### 检索方式

- PDF 共 117 页，文本可抽取，但 OCR 字形有少量错字。
- 适合用于口语解释、现代比喻和课程入口，不替代主书原文。

### 当前已定位的主题页

- PDF 第 2 页：何为易经，群经之首、群经之始等入门说法。
- PDF 第 7-9 页：何为阴阳；阴阳相对、会变动、会合一；“孤阴不生，独阳不长”；阳可理解为理想，阴可理解为脚踏实地实现理想。
- PDF 第 10-13 页：何为太极；阴阳和太极的关系；“一阴一阳，是为道”。
- PDF 第 15 页：何为八卦；“易有太极，是生两仪；两仪生四象，四象生八卦”；阴阳分不开。
- PDF 第 51 页左右：六十四卦、六爻、从下往上的读法。
- PDF 第 54-59 页左右：乾卦六阶段，潜、现、惕、跃、飞、亢。
- PDF 第 62-70 页左右：坤卦、乾坤配合、该乾就乾、该坤就坤。
- PDF 第 75 页：泰到否、否极泰来、持盈保泰。
